 🚀 ATS-Official Resume Studio

A modern, fast, and 100% free **ATS-Optimized Resume Builder** web application designed and developed by **Vaibhav Kumar**. 

✨ Key Features
* **100% Free & No APIs Required:** Runs entirely client-side right inside your browser.
* **ATS-Friendly Format:** Clean typography, standard section headings, and optimized structure for automated recruiter scanners.
* **Multi-View Workflow:** Seamlessly switch between the secure input form and a pristine full-page A4 resume preview.
* **Photo Upload Support:** Add your professional passport-sized photo with built-in size validation.
* **Comprehensive Sections:** Includes Full Name, Job Role, Professional Summary, Work Experience & Impact Bullets, Education, Hard/Soft Skills, and Certificates & Key Achievements.
* **Microsoft / PDF Compatible:** Direct one-click **Print / Save as PDF** functionality optimized for standard A4 pages.

🛠️ Built With
* **HTML5**
* **Tailwind CSS** (via CDN)
* **Vanilla JavaScript** (Secure & Optimized DOM handling)

📂 How to Run Locally
1. Download or clone this repository.
2. Save the main file as `index.html`.
3. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, etc.) and start building your elite resume!
